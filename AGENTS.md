# Agent Instructions

Before making changes in this repository, read [PROJECT_RULE.md](PROJECT_RULE.md) and the relevant [Team Agreement and DoD](docs/TEAM_AGREEMENT_AND_DOD.md).

Publish a task plan before implementation or external writes. Read-only discovery to prepare that plan is allowed. Save a plan under docs/plans for substantial work. Do not require another approval for routine work the user has already authorized.

Preserve unrelated user changes, verify results, protect secrets and report actual review/deployment/acceptance status. Follow higher-priority instructions and the user's current scope.
